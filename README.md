# Portfólio Pessoal — Fernanda Magalhães 

## Sobre o projeto

Este projeto consiste no desenvolvimento de um
portfólio pessoal, criado para apresentar minha
trajetória, formação acadêmica, habilidades e projetos.

O objetivo é aplicar conhecimentos de desenvolvimento
web, utilizando HTML e CSS, além de fundamentos
de design e acessibilidade.

## Tecnologias utilizadas

- HTML5
- CSS3

## Funcionalidades

- Apresentação pessoal
- Formação acadêmica
- Apresentação de projetos
- Seção de habilidades
- Navegação entre as seções
- Imagens com textos alternativos para acessibilidade

## Projetos apresentados

O portfólio apresenta experiências e projetos
desenvolvidos durante minha trajetória acadêmica,
incluindo um projeto relacionado à astronomia.

## Objetivo acadêmico

Projeto desenvolvido como atividade acadêmica
do curso de Análise e Desenvolvimento de Sistemas,
com o objetivo de aplicar conceitos de estruturação
de páginas web, organização visual e acessibilidade.
